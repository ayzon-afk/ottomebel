# OTTO MEBEL — демо-сайт

Демо-версия сайта для [OTTO MEBEL](https://ottomebel.uz) — кухни и мебель на заказ, Ташкент.

Чистый HTML / CSS / JS, без сборки. Открыть `index.html` или через GitHub Pages.

- Каталог 14 кухонь с фильтрами по стилю и цвету
- Карточка модели с примеркой цвета фасада
- Калькулятор стоимости кухни (демо-цены в `js/calculator.js`)
- RU / UZ, избранное, форма заявки с маской +998
